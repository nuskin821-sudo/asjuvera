# 쥬베라 AS 자주 묻는 질문 초안 (반복 고장 기준, 11/20 업무판 집계)

최미영 실장님·김은진 님이 고쳐서 확정합니다. 금액·기간은 'AS 비용' 탭이 기준입니다.

## 신형뷰러: 속눈썹이 안 집혀요 / 손잡이가 부러졌어요 (최근 60일 107건, 가장 많음)
- 증상: 손잡이·경첩 파손, 고무 들뜸으로 속눈썹이 안 집힘.
- 구매 1년 이내: 무상 교환. 롯데택배 수거 접수 후 새 제품 출고.
- 1년 이후: 유상 AS는 공장 일정으로 2027년 1월부터 접수 재개(현재 안내 문구 사용).
- 온열은 되는데 안 집히는 경우도 손잡이 파손으로 봅니다.

## 프리미엄 플러스·트리플: 충전해도 금방 꺼져요 (최근 60일 각 17건·12건)
- 증상: 완충 후 짧게 작동하고 꺼짐, 충전 표시등 깜빡임 → 배터리 고장.
- 확인 전 안내: 전용 충전선으로 충분히 충전해 보기.
- 1년 이후 유상 교환(프리미엄 플러스 4.5만/6만, 트리플 5.5만/8만).

## 듀얼 딥웨이브: 헤드 부품(금속 핀)이 빠졌어요 (최근 60일 15건)
- 증상: 전극 헤드의 금속 부품 탈락.
- 1년 이내 무상, 이후 유상(금액 확인 필요: 비용표 12만 / 문자양식 9만).

## 베라건(현대홈쇼핑): 쓰기 어렵다·아프다·힘이 없다 (최근 60일 15건)
- 대부분 사용 후 반품 요청. 반품 가능 여부는 현대홈쇼핑 규정과 제품 상태 확인 후 안내.
- 구성품 문의 9건: 헤드 4종·충전선·파우치 동봉 여부 확인.
