# 쥬베라 AS 업무판

- `index.html` : 견본 화면 (예시 자료, 저장되지 않음). 공개 주소로 보이는 화면입니다.
- `apps-script/Code.gs`, `apps-script/index.html` : 실제 업무용 프로그램. 지금 쓰는 AS 구글 시트를 그대로 저장소로 씁니다.

## 동작 방식

- 시트 → 보드 : 직원이 시트에 적은 내용을 1분마다 읽어 카드로 보여 줍니다. 탭(as / 수거완료 / 유상AS입금대기 / 출고예정 / 보류 / 처리완료)과 진행사항으로 단계를 판단합니다.
- 보드 → 시트 : 보드에서 누르면 그 건의 회수여부·문자안내·진행사항·출고일자·송장번호·비고를 적고, 단계에 맞는 탭으로 줄을 옮깁니다.
- 시트에 더하는 것 : 각 탭 V열 `보드번호`, W열 `보드자료`, 그리고 `직원`·`설정` 탭. 기존 칸은 바꾸지 않습니다.
- 2026-06-01 이전 접수 건은 보드에 올리지 않습니다.
- 현대홈쇼핑반품 탭은 아직 연결하지 않았습니다.

## 설치 순서 (먼저 사본 시트에서)

1. AS 시트에서 [파일 > 사본 만들기]로 시험용 사본을 만든다.
2. 사본에서 [확장 프로그램 > Apps Script]를 열고 `Code.gs` 내용을 붙여 넣는다.
3. HTML 파일을 `index` 이름으로 추가하고 `apps-script/index.html` 내용을 붙여 넣는다.
4. [배포 > 새 배포 > 웹 앱]: 실행 계정 = 웹 앱에 액세스하는 사용자, 액세스 = Google 계정이 있는 모든 사용자.
5. 처음 연 사람이 `직원` 탭에 등록된다. 직원의 이메일·이름·역할(상담/창고/대표)을 `직원` 탭에 적는다. 직원은 시트 편집 권한이 있어야 한다.
6. `설정` 탭의 입금계좌 칸에 안내문에 들어갈 계좌를 적는다.
