# 쥬베라 AS 업무판

- `index.html` : 견본 화면 (예시 자료, 저장되지 않음). 공개 주소로 보이는 화면입니다.
- `apps-script/Code.gs`, `apps-script/index.html` : 구글 로그인으로 실제 업무에 쓰는 프로그램. 저장용 구글 시트의 [확장 프로그램 > Apps Script]에 넣어 씁니다.

## 실제 운영 세팅 순서

1. 저장용 구글 시트를 새로 만든다 (기존 AS 시트는 건드리지 않는다).
2. 그 시트에서 [확장 프로그램 > Apps Script]를 열고 `Code.gs` 내용을 붙여 넣는다.
3. HTML 파일을 `index` 이름으로 추가하고 `apps-script/index.html` 내용을 붙여 넣는다.
4. [배포 > 새 배포 > 웹 앱]: 실행 계정 = 웹 앱에 액세스하는 사용자, 액세스 = Google 계정이 있는 모든 사용자.
5. 처음 연 사람이 '직원' 탭에 대표로 등록된다. 직원의 이메일·이름·역할(상담/창고)을 '직원' 탭에 적고, 시트를 그 직원에게 편집자로 공유한다.
6. '설정' 탭의 입금계좌 칸에 안내문에 들어갈 계좌를 적는다.

들어올 수 있는 사람은 시트 편집 권한이 있고 '직원' 탭에 이메일이 적힌 사람뿐입니다.
